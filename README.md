# Leapbound

2D платформер на Unity с управляемым игроком, патрулирующими врагами, системой очков и уровней, а также динамическим UI и звуковым оформлением.
Игрок исследует загадочный мир, сражается с монстрами. Главная цель — пройти все уровни, набрав максимальное количество звёзд.

   ## 🎮 Основные функции

### Игрок
- Ходьба / бег, **двойной прыжок**, knockback и i-frames при уроне
- Атака мечом и урон прыжком на голову врага
- Респаун на чекпоинте после смерти / `DeathZone`
- Движущиеся платформы, падающие платформы, батут
- Конфиг параметров через **ScriptableObject** (`PlayerConfig`)

### Враги и окружение
- **PigEnemy** — патруль
- **PlantEnemy** — дальний бой (пули + object pooling)
- Монеты, аптечки, финиш-зона, parallax-фон

### Уровни и прогресс
- Система очков и подсчёта звёзд (1–3) по результату уровня:
  - ≥100 очков — 3 звезды
  - ≥50 очков — 2 звезды
  - Дошёл до финиша — 1 звезда
- Сохранение лучшего результата с помощью `PlayerPrefs`.
- MainMenu с отображением прогресса по звёздам для каждого уровня.
- Возможность перезапуска уровня и перехода к следующему.

### Мета / UI
- Main Menu с прогрессом по звёздам и разблокировкой уровней
- HUD (счёт, здоровье), пауза, настройки музыки / SFX
- Перезапуск уровня и переход к следующему после победы

### Ключевые решения:
- **Dependency Injection (Zenject)** — биндинги на уровне проекта и сцены
- Логика игрока вынесена в классы с `ITickable` / `IFixedTickable` (не всё завязано на MonoBehaviour)
- Сервисы за интерфейсами: 
- События для UI и геймплея 
- Object pooling для VFX / пуль
- Cinemachine для камеры, Tilemap для уровней, TextMeshPro для UI

## О проекте
Игрок проходит серию уровней, сражается с врагами (stomp + меч), собирает монеты и доходит до финиша.  
Результат уровня оценивается в **1–3 звезды** по очкам; прогресс и разблокировка уровней сохраняются через `PlayerPrefs`.
В проекте **4 игровых уровня** + главное меню.
